Built-in embedding models and content retrievers for Retrieval-Augmented Generation. {/} {#roq/featureCard icon="fa-plug" title="MCP Support"} Full Model Context Protocol support -- expose Jakarta EE beans as MCP servers with tools, prompts, and resources, or connect to external MCP servers as a client. {/} {#roq/featureCard icon="fa-microchip" title="WASM Tools"} Run WebAssembly WASI modules as MCP tools via the Chicory runtime. Sandboxed execution with configurable memory limits and network access. {/}

Quick Install

Provision the feature pack alongside WildFly using the WildFly Maven Plugin:

<feature-packs>
  <feature-pack>
    <location>org.wildfly:wildfly-galleon-pack:39.0.0.Final</location>
  </feature-pack>
  <feature-pack>
    <location>org.wildfly.generative-ai:wildfly-ai-feature-pack:0.20.2-SNAPSHOT</location>
  </feature-pack>
</feature-packs>
<layers>
  <layer>cloud-server</layer>
  <layer>ollama-chat-model</layer>
</layers>

See the Getting Started guide for full setup instructions.
